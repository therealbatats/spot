Sky Patches Over Time. The sky looks still. It isn't.

A free website that turns real NASA SPHEREx infrared images of any patch of sky into a little video, so anyone can spot what moved or changed.

The problem

  • SPHEREx maps the whole sky every six months in 102 infrared colours — images of more than a billion objects, according to the challenge statement.
  • Nearby stars, brown dwarfs, asteroids and maybe new planets give themselves away by moving between images. Pluto was found this way in 1930.
  • But SPHEREx sees a different colour in every image: compare carelessly and you invent changes.
  • The challenge: type coordinates, see the images of that patch like a little video, easily, for anyone.

The tool

How it stays honest — and keeps working

  • Compares only matched wavelengths (within half a filter width) or the band range shared by every visit.
  • One brightness scale per comparison; SPHEREx's own quality flags shown.
  • Provenance for every frame: date, detector, wavelength, link to the original file.
  • IRSA's search API returned HTTP 502 throughout our build (1:41–5:55 PM Baghdad), so we indexed all 97,434 SPHEREx visits from the public cloud copy. Any browser can now build a field live, reading ~2 MB per image, no server.

Spot the wanderer · Planet X simulator

Spot the wanderer: markers hide, you tap what moved, the site explains it.

Planet X simulator SIMULATED draws a pretend planet into real images at 100–1000 AU, moving by parallax and orbit.

Lesson: in Barnard's Star's field, a planet at 500 AU would jump ~14 arcminutes between visits six months apart — wider than the whole image.

Honest answer: a real Planet Nine (~mag 22–25) is probably too faint for SPHEREx (~18.4–19.5 per channel).
